
# MikroJava Compiler

A compiler for the MikroJava programming language, implemented in Java as an academic compiler construction project.

## Technologies

- Java
- JFlex
- CUP

## Compiler Components

- Lexical analysis
- Syntax analysis
- Semantic analysis
- Code generation for the MikroJava virtual machine

## Overview

The compiler processes MikroJava source code through multiple compilation phases, performing language analysis and generating executable code for the target virtual machine.

## About

Academic project developed as part of the Compiler Construction course at the University of Belgrade, School of Electrical Engineering.
